# Nädal 0

## Nädala eesmärk

Nädal 0 eesmärk oli seadistada UrbanStyle meeskonnale nimega TURUNDUS ühine töökeskkond, panna paika rollid ja koostööpõhimõtted.

## Nädal 0 väljundid

Selle nädala jooksul seadistame ja ühendame järgmised keskkonnad:

- GitHub – meeskonna ühine repo ja dokumentatsioon
- Supabase – ühine andmebaas
- NotebookLM – ühine õppimise ja RAG keskkond
- Team Charter – meeskonna ühised kokkulepped
