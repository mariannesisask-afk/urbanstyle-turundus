# Nädal 0

## Nädala eesmärk

Nädal 0 eesmärk oli luua UrbanStyle.ltd meeskonnale nimega TURUNDUS ühine töökeskkond ning panna paika vajalikud töövahendid, rollid ja koostööpõhimõtted.

## Nädal 0 väljundid

Selle nädala jooksul seadistasime ja ühendasime järgmised keskkonnad:

- GitHub – meeskonna ühine repo ja dokumentatsioon
- Supabase – ühine andmebaas
- NotebookLM – ühine õppimise ja RAG keskkond
- Team Charter – meeskonna ühised kokkulepped
