
## NÄDAL 5 — Andmete visualiseerimise disain


## Nädala eesmärk

- **Visualiseerimise disainipõhimõtete omandamine:** Õppida valima õigeid diagrammitüüpe (joondiagramm, tulpdiagramm, sektor-/sõõrikdiagramm, KPI kaardid), rakendama visuaalset hierarhiat ja F-mustrit, vähendama müra (data-ink ratio)
 ning järgima värviteooriat ja ligipääsetavust.
- **Visualiseerimisraja valik ja rakendamine:** Võtta kasutusse kas Track A (Power BI Desktop) või Track B (Python + Plotly + Streamlit) vastavalt valitud rajale.
- **Näidisettevõtte UrbanStyle.ltd investor-dashboard'i ehitamine:** Luua ühele ekraanile mahtuv prototüüp, mis vastab CEO Kristi Tamme strateegilistele küsimustele.
- **Põhielementide ja filtrite koondamine:** Seadistada KPI kaardid, käibe joondiagramm, toodete horisontaalne tulpdiagramm, linnade/kanalite jaotus ning interaktiivsed filtrid.
- **GitHubi portfoolio täiendamine:** Dokumenteerida töö oma repository's, lisada README faili ekraanipilt dashboard'ist, seotud SQL-päringud ning selgitused disainivalikute ja ärimõju kohta.
